# Calculus Study Notes

Following Stewart, J. (2021). *Calculus: Early Transcendentals* (9th ed.). Cengage Learning.

## Structure

- One notebook per book section (`chapter_number`/0Y_section_name.ipynb`).
- Each notebook follows a fixed 6-step template per concept: **Concept → Notation → Worked example → Code → Visualization → Key question**.
- Use plain Python with standard math libraries (math, numpy) to implement and explore concepts computationally.
- Use external tools like Desmos or GeoGebra for interactive visualizations when helpful.
- For Python visualizations, create reusable plotting functions in a shared module to avoid copy-pasting across notebooks.
